## 실행 기록

- Fabric 최초 접속은 인증 리디렉션 중 ERR_ABORTED를 반환했습니다. 재접속에서 Fabric 홈 탭을 확인했으며 상세 화면 확인을 이어갑니다.
- Azure 포털은 인증 화면을 열었습니다. 아직 유료 리소스 생성이나 기존 리소스 변경은 하지 않았습니다.
- 이후 인증이 완료됐고, 새 리소스 그룹과 F2 용량을 배포했습니다. 배포 이름은 Microsoft.Fabric-20260909225426, 포털 시작 표시는 2026-09-09 22:56:13입니다.
- Workspace settings > Workspace type에서 새 용량 할당을 확인했습니다.
- QMS Lakehouse 생성 시 Lakehouse schemas 체크를 유지했고 생성 후 dbo를 확인했습니다. 기존 16번 이미지의 체크 해제 상태와 다릅니다.
- Fabric 탭이 보이지 않는 상태에서 자동화 클릭의 안정성 대기가 반복적으로 시간 초과했습니다. 키보드 입력 및 같은 UI 요소의 클릭 이벤트로 진행했습니다. 이를 노트북 오류나 README 메뉴 부재로 판정하지 않습니다.
- 사용자 추가 지침 이전에 로컬 문서 링크 검사, 노트북 파일 읽기 및 테스트 실행 시도가 있었습니다. 외부 스크립트로 데이터를 생성하거나 Fabric에 적재한 적은 없습니다. 추가 지침 이후 로컬 스크립트 실행을 중단했습니다.

### QMS 원본 실행과 진단

1. 제공 QMS 파일을 UI의 Import > Notebook > From this computer > Upload로 가져왔습니다.
2. OneLake catalog에서 같은 작업 영역의 Lakehouse 유형 qms_lakehouse를 선택했습니다. 초기 자동화 선택은 반영되지 않아 다시 행을 선택하고 checkbox checked / Add enabled를 확인한 후 연결했습니다.
3. Run all을 시작했고 Spark 세션은 5초 만에 시작됐습니다. 원본 첫 설정 셀이 계속 실행 중으로 표시됐지만 대상 출력과 숨김 키 입력창은 나타나지 않았습니다.
4. Cancel all 후 UI에 `13 executions succeeded. {1}Kernel is now idle`가 나타났지만 적재 출력·실행 카운트·저장값 근거가 없어 성공으로 인정하지 않았습니다.
5. Fabric의 실행 복사본에 읽기 전용 진단 셀 1개를 추가했습니다. 로컬 원본 노트북 4개는 수정하지 않았습니다. 진단은 컨텍스트 ID, 키의 존재 여부(Boolean), `SHOW TABLES IN dbo`만 조회했고 데이터 쓰기는 하지 않았습니다.
6. 초기 진단 실행도 결과 표시가 지연돼 세션을 종료했습니다. 새 브라우저 탭에서 같은 노트북을 열고 읽기 전용 진단만 재실행한 결과 17초에 완료됐습니다. 세션 준비 11초 85ms, 명령 실행 6초 649ms, 완료 표시는 2026-09-09 23:15:55입니다.
7. 실제 결과는 아래와 같습니다. 모든 ID는 이번 신규 대상과 일치하고, 키·MES 스냅샷은 없으며 dbo 테이블 목록은 비어 있습니다.

9. 메타데이터 검사가 어디까지 진행됐는지 알아보려고 진단 셀을 전역 변수 존재 여부 및 defaultSchema 확인용 두 줄로 바꿨으나 해당 셀은 대기 상태였고 결과를 얻지 못했습니다. 따라서 메타데이터 검사 완료나 getpass 도달을 확정하지 않습니다.
10. Stop session 후 `Session stopped`와 취소 상태를 확인했습니다. 안전장치를 끄거나 소스에 키를 넣거나 외부 스크립트로 적재하지 않았습니다.

### 관측 한계

- 브라우저에서 Notebook content의 HEAD/PUT 요청에 `net::ERR_ABORTED`, Spark `driverlog/metadata/jobGroup_4`에 HTTP 404가 관측됐습니다. 명령 실행이 성공한 진단에서도 일부 요청 오류가 있었으므로 이 오류만으로 전체 Spark 장애나 적재 실패 원인을 확정하지 않습니다.
- 원본 설정 셀은 REST 메타데이터 조회와 getpass 입력을 함께 수행합니다. 키가 없고 입력창이 나타나지 않았다는 것은 확인했지만, 정확한 대기 지점은 확인하지 못했습니다.
- 실행본 다운로드를 UI의 Download as > Notebook (.ipynb)로 두 번 시도했지만 30초 내 다운로드 이벤트가 발생하지 않았습니다. 보존된 성공 실행본이 있다고 주장하지 않습니다.
- 이번 실행에는 MES 인증키를 입력한 적이 없습니다. 비밀번호·토큰·키를 채팅·소스·캡처로 전달하지 않았습니다.
- FDC/MES/온톨로지 노트북은 아직 Fabric에서 실행하지 않았습니다. Eventhouse와 MES Lakehouse, 온톨로지, Graph, 데이터 에이전트도 아직 생성하지 않았습니다.
- 비즈니스 사전 질문·공통 지침·5개 본질문·후속 질문은 모두 미실행입니다. 과거 에이전트 결과나 샘플 답변으로 대신 평가하지 않습니다.

## 가이드 중간 평가

- **리소스 생성 경로:** F2 선택·배포·작업 영역 생성·할당·QMS Lakehouse 생성·노트북 가져오기·카탈로그 연결 경로는 실제 UI에서 확인했습니다. 자동화 클릭 지연은 별도로 기록했습니다.
- **이미지 정확도:** 실제로 열어 대조한 기존 03번 이미지는 F2·가격·Select가 일치합니다. 기존 16번 이미지는 Lakehouse schemas가 꺼져 있어 최신 본문 및 노트북 요구사항과 반대입니다. 이름·위치·Create 위치는 참고할 수 있지만 설정 예시로 그대로 사용하면 안 됩니다.
- **실행 가능성:** 현재 README만으로 신규 환경의 QMS 적재를 완료하지 못했습니다. 숨김 입력이 나타나지 않을 때의 대안은 '런타임 비밀값 공급 준비'에 그쳐 실행 가능한 구체적 절차가 없습니다.
- **문서 일관성:** 기존/신규 워크스페이스의 혼재, 구식 파라미터 이미지, 존재하지 않는 테스트 경로는 정리가 필요합니다.
- **평가 범위:** 모든 기존 이미지를 개별 검토한 것은 아닙니다. 7절 이후 실제 실행·이미지 대조와 온톨로지 질문 정답 비교가 남아 있어 전체 정확도 점수나 전체 통과율을 산출하지 않습니다.
