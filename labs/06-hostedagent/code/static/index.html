같은 질문의 모드별 실행 비교

질문을 실행하면 비교 결과를 표시합니다.

현재 KB·동일 질문만 비교합니다. 최근 완료 실행 10개를 브라우저 메모리에만 유지하며 새로고침 시 초기화합니다. 추가 호출에는 동일 소스의 병렬 하위 검색도 포함되며 재검색 루프 수와 다릅니다. KB 시간은 계획·검색·합성의 wall time입니다. 첫 답변/전체 시간은 Agent 시작 기준이며 브라우저 시간에는 인증·네트워크·기동 지연도 포함됩니다. 단일 실행으로 성능 우열을 단정하지 마세요.

같은 응답을 파싱합니다. 토글 변경은 추가 조회·모델 호출·비용을 발생시키지 않습니다.

질문을 실행하면 반환된 계획·검색·근거 연결을 여기에 표시합니다.

KB 조회 후 모델 답변이 실시간 생성됩니다. 부분 실패는 전체 성공이 아니며, 요청·가설을 승인·확정 사실로 해석하지 마세요. 세션과 토큰은 서버 메모리에서만 유지됩니다.
