# 제조 업무 시나리오 이메일 발송 프롬프트

## 사용 안내

- **목표:** 가상 업무 이메일 10건을 발송해 Work IQ가 업무 컨텍스트를 취합하고 Fabric IQ에 질문할 수 있는 시작 자료를 만듭니다. [Fabric IQ 비즈니스 시나리오](../02-fabric-iq/helper-new/README-ontology-business-scenarios.md)의 확장 A~E에 각각 2건씩 대응합니다.
- **현재 실습 범위:** [04 Work IQ 노트북](01_workiq_rest.ipynb)은 메일 03·04의 LOT0004 출하 검토를 조회하고 Fabric에서 추가로 확인할 질문을 정리합니다. Work IQ가 Fabric을 자동 호출하는 흐름이나 확장 A~E 전체의 실행을 이 파일이 구현하지는 않습니다.
- **준비:** 메일 발송 기능이 있는 도구와 정상 인증된 발신 계정·발송 권한이 필요합니다. 후속 실습에는 수신 메일을 조회할 수 있는 Work IQ 환경과 해당 문서의 데이터·온톨로지·Data Agent 준비가 필요합니다. 계정의 라이선스·사용 권한과 조직의 메일 정책을 확인합니다.
- **실행:** 아래 코드 블록 전체를 메일 발송 도구가 있는 대화에 붙여 넣습니다. 재사용 전에 수신 주소와 실습 표식 `IQ-DEMO-20260922`를 확인하고, 새 실행을 구분하려면 표식을 일괄 변경합니다. 로트·설비 ID는 실제 실습 자료와 대조합니다.
- **예상 결과:** 이번 실행의 보낸 편지함에 수신 주소가 일치하는 서로 다른 이메일 10건이 있습니다. 수신함 도착과 Work IQ 검색 반영은 별도로 확인합니다. 이 프롬프트만으로 스팸 분류 해소를 보장하지 않습니다.
- **정리:** 실습 종료 후 실제 보낸 편지함·수신함에서 해당 실행의 표식과 제목을 확인해 불필요한 실습 메일만 정리합니다. 이 파일은 메일 발송이나 삭제를 자동 실행하지 않습니다. 후속 Fabric IQ 조회에는 Fabric 용량이 사용됩니다.
